How to practise

  • 1Try every problem alone for 30–40 minutes before looking at hints or asking Claude.
  • 2Say the time and space complexity out loud, then code it in Python.
  • 3If you needed help, mark it and solve it again from scratch 3 days later.
  • 4For "Learn" items, write the structure yourself in Python before using the built-in (heapq, collections.deque).

Sync between devices

Progress is saved to progress.json on the progress branch of this repo, so your phone and computer see the same ticks. Each device needs a GitHub token once.

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → DSA-Plan. Permissions: Contents: Read and write. Nothing else.
  3. Copy the token and paste it here.

Problems link to LeetCode. The token stays in this browser only and can reach only this repo.
